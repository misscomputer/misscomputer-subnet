# IANA-derived registry data

`pkg/netpolicy/iana-special-purpose.v1.json` is an owner-authored compilation
derived from the IANA IPv4 and IPv6 Special-Purpose Address Registries. The
upstream registry pages are:

- https://www.iana.org/assignments/iana-ipv4-special-registry/
- https://www.iana.org/assignments/iana-ipv6-special-registry/

IANA maintains the source registries; IANA does not endorse this project. The
committed compilation is distributed with this project under AGPL-3.0-only.
Its generated-at field and source URLs identify the reviewed registry input.
