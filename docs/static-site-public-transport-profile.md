# Testnet public transport profile

`misscomputer-static-probe` defaults to the original strict static response check. The optional `--public-transport-policy` and `--public-transport-policy-sha256` pair enables `cloudflare-framing-v1` **only** for signed V3 `test/581` epochs under an exact, local policy pin. The policy binds the assignment-manifest trust-policy digest and the `on.miss.computer` route suffix. The combined organic/static validator CLI has no profile switch. This profile does not change miner-probe-attestation v2, static-handler.v1, or the signed release/index.

The miner signature is still verified for the nonce, validator, request, endpoint incarnation, ticket, site, time, status, body hash, and **full expected normative header digest**, including representation `Content-Length`. The public transport is checked separately for status, complete raw body length and hash, stable normative headers, forbidden headers, and valid HTTP framing. For HTTP/1.1, exactly one canonical `Content-Length` matching the signed representation length or exactly one `Transfer-Encoding: chunked` is accepted for GET. HEAD may omit both. HTTP/2 and HTTP/3 may omit length but may not carry transfer coding. Duplicate, conflicting, malformed or compressed responses fail. There is no automatic fallback from strict mode.

The validator writes v2 static observations, evidence records and epoch scores with the profile ID and policy digest in their canonical digests; v1 bytes and replay stay unchanged. Actual public headers and HTTP version are retained, bounded, and replayed against the authenticated index. A signed opaque header mismatch is classified as a path ambiguity, **not** a miner content fault or fraud. V2 evidence cannot be mixed into v1 epochs. Mainnet is refused by the pinned policy.

This profile is a testnet integration repair, not blanket release approval. A full signed public-path epoch, private collector pin/replay, D09 recovery evidence, and independent release sign-off remain required before general static admission or weights are enabled.
